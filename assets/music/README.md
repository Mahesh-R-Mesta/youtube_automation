# Background Music

Place royalty-free background music tracks here.

The pipeline automatically picks the **first** audio file found in this directory.

## Supported formats

`.mp3`, `.wav`, `.ogg`

The track will automatically loop if shorter than the video, and will be mixed at **15% volume** under the narration.

## Where to get free music (no copyright claim)

| Source | License | Notes |
|--------|---------|-------|
| [Pixabay Music](https://pixabay.com/music/) | Free for commercial use | No attribution required |
| [Free Music Archive](https://freemusicarchive.org/) | Varies (check CC license) | Filter by CC0 or CC-BY |
| [YouTube Audio Library](https://studio.youtube.com/channel/UCxxxxxx/music) | Free for YouTube | Must use YouTube Studio |
| [Bensound](https://www.bensound.com/) | Free with attribution | Add credit in description |

## Recommendation

Download a calm, neutral instrumental track (e.g., "news background", "documentary ambient") at 128+ kbps MP3 and save it here as `background.mp3`.

## Note

If this directory is empty, the pipeline will produce the video with narration only (no background music). This is perfectly fine.
